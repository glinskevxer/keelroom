# keelroom commands

Generated by `npm run commands`. Do not edit by hand.

## Options on every command

- `-v, --version` print the version and exit
- `-c, --config <path>` settings file to read
- `-d, --district <code>` district code to work in
- `--database <path>` district file to open
- `--now <instant>` treat this as the current time
- `--operator <name>` who is at the terminal, for the audit trail
- `-f, --format <format>` text or json

## Commands

### `keelroom advice`

what a ship could do, before she orders

### `keelroom advice draught`

what each draught buys her over a period

Options:
  - `--from <time>` start of the period
  - `--days <days>` how many days
  - `--low <metres>` the lightest draught to try
  - `--high <metres>` the deepest
  - `--step <metres>` how far apart the rungs are
  - `--outbound` she is sailing rather than arriving

### `keelroom advice deepest`

the deepest she can come and still have a window worth having

Options:
  - `--from <time>` start of the period
  - `--days <days>` how many days
  - `--want <minutes>` how long a window she wants
  - `--outbound` she is sailing rather than arriving

### `keelroom advice days`

the best days of the next several for a ship at a draught

Options:
  - `--from <time>` start looking here
  - `--days <days>` how many days to look over

### `keelroom advice dredging`

which reach would buy the most window if it were deepened

Options:
  - `--from <time>` start of the period
  - `--days <days>` how many days of movements to study
  - `--by <metres>` how much deeper to try

### `keelroom audit show`

### `keelroom audit recent`

Options:
  - `--limit <count>` how many

### `keelroom audit by`

### `keelroom billing`

### `keelroom billing quote`

Options:

### `keelroom billing issue`

### `keelroom billing show`

### `keelroom billing pay`

Options:
  - `--at <time>` when it was received

### `keelroom billing credit`

### `keelroom billing statement`

### `keelroom billing overdue`

### `keelroom plan`

  - `--wind <knots>` wind for the plan

  - `--swell <metres>` significant wave height
  - `--density <thousandths>` water density, salt water being 1025

### `keelroom plan confirm`
